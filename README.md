# العربية — الثالثة إعدادي (تطبيق أندرويد)

تطبيق تعليمي تفاعلي متكامل مخصص لمادة اللغة العربية للسنة الثالثة من سلك التعليم الثانوي الإعدادي وفق المنهاج التعليمي المغربي الرسمي. يهدف التطبيق إلى تمكين المتعلمين والمتعلمات من استيعاب مضامين المنهاج الدراسي بأسلوب حديث وجذاب، من خلال عرض منظم للمكونات الدراسية (النصوص القرائية، الدرس اللغوي، التعبير والإنشاء، ونماذج الامتحانات)، مدعوماً ببطاقات شرح بيداغوجية، تمارين تفاعلية متنوعة، ونظام ذكي للمراجعة المتباعدة وتكرار الأخطاء لترسيخ التعلمات.

يتميز التطبيق بواجهة مستخدم عصرية مبنية بأحدث تقنيات Jetpack Compose وتصميم Material Design 3، مع دعم كامل للوضع الليلي (باللون الأزرق الهادئ المريح للعين)، والتحكم في حجم الخط وعرض التشكيل وسرعة النطق الصوتي للدروس (Text-to-Speech). كما يحتوي على بنك شامل لنماذج الامتحانات المحلية الموحدة وفروض المراقبة المستمرة مع مؤقت زمني وشبكات تصحيح معيارية دقيقة تضمن الجاهزية التامة للاستحقاقات الإشهادية.

---

## المكوّنات والوحدات الدراسية

ينتظم المنهاج الدراسي للأسدوس الأول في **3 وحدات دراسية** رئيسية تتوزع عبرها المكونات كالآتي:

1. **القيم الإسلامية** (الوحدة الأولى): نصوص قرائية، دروس لغوية (اسم الفاعل وصيغ المبالغة، عملهما، واسم المفعول وعمله)، ومهارات التعبير والإنشاء (التلخيص، تصميم اليوميات).
2. **القيم الوطنية والإنسانية** (الوحدة الثانية): نصوص قرائية وشعرية وطنية، دروس لغوية (أسماء الزمان والمكان، واسم الآلة)، ومهارات الإنشاء (كتابة سيرة ذاتية أو غيرية).
3. **المجال الحضاري** (الوحدة الثالثة): نصوص فكرية وحضارية، دروس لغوية (النسبة، والمعاجم اللغوية)، ومهارات الإنشاء (التعقيب والتعليق).
4. **نماذج الامتحانات والتقويمات**:
   - تقويمات الوحدات الدراسية (تقويم الوحدة 1، 2، 3).
   - التقويم الإجمالي للأسدوس الأول.
   - الفروض المنزلية وفروض المراقبة المستمرة.
   - نماذج الامتحانات الموحدة المحلية (دورة يناير) مرتبة تاريخياً.

## كيف تضيف درساً جديداً في `lessons.json`

تُعرّف الدروس داخل الملف `app/src/main/assets/lessons.json` وفق المخطط الهيكلي المحدد في `meta.schema`. يتضمن كل درس الحقول الأساسية: `id`، `component` (`texts` أو `language` أو `writing`)، `semester` (`1`)، `unit` (`1` أو `2` أو `3`)، `order`، `title`، `summary`، ومصفوفتي `cards` و`exercises`.

### 1. أنواع البطاقات البيداغوجية (`cards`)

- **قاعدة (`rule`):**
```json
{
  "type": "rule",
  "title": "تعريف اسم التفضيل",
  "points": [
    "اسم التفضيل اسم مشتق على وزن أَفْعَل للدلالة على شيئين اشتركا في صفة وزاد أحدهما على الآخر.",
    "يُشتق مباشرة من الفعل الثلاثي التام المثبت المتصرف القابل للتفاضل غير الدال على عيب أو لون."
  ]
}
```

- **أمثلة وشواهد (`example`):**
```json
{
  "type": "example",
  "title": "أمثلة انطلاق",
  "items": [
    {"example": "العلمُ أنفعُ من المالِ.", "note": "صيغ من الفعل نَفَعَ مباشرة"},
    {"example": "المحيطُ أشدُّ زُرقةً من النهرِ.", "note": "صيغ بطريقة غير مباشرة لمجيء الوصف على أفعل فعلاء"}
  ]
}
```

- **إعراب ونماذج إعرابية (`irab`):**
```json
{
  "type": "irab",
  "title": "نموذج إعرابي",
  "steps": [
    {"word": "العلمُ", "role": "مبتدأ مرفوع وعلامة رفعه الضمة الظاهرة على آخره"},
    {"word": "أنفعُ", "role": "خبر مرفوع وعلامة رفعه الضمة الظاهرة على آخره"}
  ]
}
```

- **حقائق وإضاءات (`facts`):**
```json
{
  "type": "facts",
  "title": "فائدة لغوية",
  "points": [
    "تُحذف همزة (أفعل) في ثلاث كلمات سماعية لكثرة الاستعمال: خَيْر، شَرّ، وحَبّ."
  ]
}
```

- **معجم ومفردات (`vocab`):**
```json
{
  "type": "vocab",
  "title": "الشروح اللغوية",
  "items": [
    {"term": "السَّجِيَّة", "meaning": "الطبيعة والخلق الفطري"}
  ]
}
```

- **خلاصة وتركيب (`summary`):**
```json
{
  "type": "summary",
  "title": "خلاصة الدرس",
  "points": [
    "شروط الصياغة المباشرة سبعة، وإذا اختل شرط نأتي بمصدر الفعل منصوباً على التمييز بعد اسم تفضيل مساعد."
  ]
}
```

- **خطوات إنجاز مهارة (`steps`):**
```json
{
  "type": "steps",
  "title": "خطوات كتابة اليومية",
  "steps": [
    "تحديد الزمان والمكان بدقة.",
    "سرد الوقائع بترتيب زمني واستعمال ضمير المتكلم.",
    "إبراز المشاعر والأثر النفسي للحدث."
  ]
}
```

- **نموذج تطبيقي للمهارة (`model`):**
```json
{
  "type": "model",
  "title": "نموذج يومية مدرسية",
  "text": "الرباط، 12 أكتوبر: استيقظت اليوم بشعور يفيض بالأمل نحو عام دراسي مفعم بالجد والتحصيل..."
}
```

- **حفظ واستظهار (`memorize`):**
```json
{
  "type": "memorize",
  "title": "أبيات للحفظ",
  "points": [
    "بلادي هواها في لساني وفي دمي *** يمجّدُها قلبي ويدعو لها فمي"
  ]
}
```

### 2. أنواع التمارين التطبيقية (`exercises`)

- **اختيار من متعدد (`mcq`):**
```json
{
  "type": "mcq",
  "question": "ما وزن صيغة المبالغة من الفعل 'صَبَرَ'؟",
  "options": ["صَبُور (فَعُول)", "صَابِر (فَاعِل)", "مِصْبَار (مِفْعَال)"],
  "answerIndex": 0,
  "explanation": "صَبُور على وزن فَعُول وهو من أوزان المبالغة القياسية الخمسة."
}
```

- **صحيح أو خطأ (`true_false`):**
```json
{
  "type": "true_false",
  "question": "يُشتق اسم الفاعل من غير الثلاثي على وزن مضارعه بإبدال حرف المضارعة ميماً مضمومة وفتح ما قبل الآخر.",
  "answer": false,
  "explanation": "خطأ؛ يُشتق بكسر ما قبل الآخر، بينما فتح ما قبل الآخر هو وزن اسم المفعول."
}
```

- **ترتيب الكلمات والجمل (`order_words`):**
```json
{
  "type": "order_words",
  "question": "رتّب الكلمات الآتية لتركيب قاعدة عمل اسم الفاعل:",
  "words": ["معموله", "الفاعل", "يرفع", "اسم", "المتعدي", "وينصب"],
  "answer": ["يرفع", "اسم", "الفاعل", "معموله", "وينصب", "المتعدي"],
  "explanation": "يعمل اسم الفاعل عمل فعله فيرفع الفاعل وينصب المفعول به إن كان متعدياً."
}
```

## كيف تضيف امتحاناً في الأصول (`app/src/main/assets`)

تُحفظ الامتحانات إما كملف فردي باسم `exam-s1-*.json` أو تُدرج ضمن مصفوفة `exams` في `local-exams-models.json`.

### شروط مجموع النقط الإلزامية:
1. `declared_total`: يجب أن يكون مساوياً دائماً لـ **20** نقطة.
2. مجموع نقط الأقسام الثلاثة (A: القراءة 8 نقط، B: الدرس اللغوي 6 نقط، C: التعبير والإنشاء 6 نقط) يجب أن يساوي تماماً `declared_total` (20.0).
3. مجموع نقط الأسئلة داخل كل قسم يجب أن يطابق مجموع نقط ذلك القسم.
4. معايير شبكة التصحيح (`rubric`) في القسم C (التعبير والإنشاء) يجب أن يطابق مجموعها نقط القسم C (6.0 نقط).

## تشغيل الاختبارات وبناء التطبيق

### 1. تشغيل الاختبارات الآلية (Unit Tests):
```bash
gradle :app:testDebugUnitTest
```
أو عبر Gradle wrapper إذا وُجد:
```bash
./gradlew test
```

### 2. بناء حزمة التطبيق (APK):
```bash
gradle assembleDebug
```
يتم إنشاء ملف الحزمة في المسار التالي:
`app/build/outputs/apk/debug/app-debug.apk`
