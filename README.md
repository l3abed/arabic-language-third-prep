# العربية — الثالثة إعدادي (تطبيق أندرويد)

تطبيق تعليمي لمادة اللغة العربية للسنة الثالثة من السلك الإعدادي وفق المنهاج المغربي، مبني بـ Kotlin وJetpack Compose وMaterial 3. يعمل دون اتصال بالإنترنت، وتُخزَّن بياناته (التقدم، والأخطاء، وجلسات الامتحانات) في الجهاز.

## المحتوى
- **الأسدسان الأول والثاني: ست وحدات و43 درساً** موزعة على ثلاثة مكوّنات: النصوص القرائية والشعرية، والدرس اللغوي، والتعبير والإنشاء.
- **تمارين تفاعلية** في كل درس: اختيار من متعدد (تُعرض الخيارات بترتيب عشوائي في كل مرة)، وصح/خطأ (موزونة بين الصحيح والخاطئ)، وترتيب الكلمات (يقبل أكثر من ترتيب صحيح، مثل الجملة الاسمية والفعلية).
- **سجل الأخطاء** لإعادة التمارين التي أخطأ فيها المتعلم.
- **بنك الامتحانات**: 15 نموذجاً (6 امتحانات محلية موحدة، و8 تقويمات للوحدات والأسدسين، وفرض منزلي).

## الامتحانات
- يبدأ المؤقت عند الضغط على «ابدأ الامتحان»، ولا يمكن إيقافه. ومدته محسوبة من وقت انتهاء محفوظ، فلا يتأثر بتدوير الشاشة ولا بإغلاق التطبيق.
- عند انتهاء الوقت يُسلَّم الفرض تلقائياً بما كُتب فيه. وزر الرجوع أثناء الامتحان يعني التسليم.
- تُحفظ الإجابات تلقائياً، وتبقى نتيجة آخر محاولة.
- بعد التسليم تظهر **نقطة تقديرية من 20** مع نقطة كل قسم وكل سؤال، والإجابات النموذجية.
- بعض الأسئلة جداول: يملأ المتعلم الخانات الفارغة، وتظهر بعد التسليم خانات صحيحة وخاطئة مع الصحيح.

### كيف تُصحَّح الإجابات (`util/ExamGrader.kt`)
التصحيح الآلي **فحص كلمات لا فهم معنى**، فالنقطة تقديرية.
- **تُهمَل** حركات التشكيل والتطويل، وتُوحَّد الهمزات والتاء المربوطة والألف المقصورة، وتُحذف أدوات الربط والتعريف الشائعة.
- يُعدّ العنصر صحيحاً إذا وُجدت كلماته الأساسية في الجواب (نصف نقطة عند التطابق الجزئي). ويُقبل أي بديل مفصول بـ «/» أو «أو» في الإجابة النموذجية.
- ما بين القوسين في الإجابة النموذجية شرح لا يُشترط كتابته.
- الأسئلة التي يحوي نصها «اضبط» أو «اشكل» أو «الضبط» **تُقارَن فيها الحركات** نفسها.
- **أسئلة الرأي** (إجابتها النموذجية تبدأ بـ «يُقبل» أو «تُقبل») تُقدَّر بحسب اكتمال الجواب.
- **التعبير الإنشائي** يقدّره المتعلم بنفسه على معايير سلّم التنقيط.

## إضافة محتوى

### درس جديد في `app/src/main/assets/lessons.json`
حقول الدرس: `id` و`component` (`texts` أو `language` أو `writing`) و`semester` و`unit` (من 1 إلى 6) و`order` و`title` و`summary` و`cards` و`exercises`.

**البطاقات (`cards`)**: لكل بطاقة `type` و`title` والحقول الآتية:

| النوع | الحقول |
|---|---|
| `rule` | `text` (اختياري) و`points` (قائمة نصوص) |
| `example` | `items`: كل عنصر `{ "text": "...", "note": "..." }` |
| `irab` | `sentence` و`steps`: كل خطوة `{ "word": "...", "irab": "..." }` و`tip` (اختياري) |
| `facts` و`vocab` | `items`: كل عنصر `{ "label": "...", "value": "..." }` |
| `summary` | `text` |
| `steps` و`memorize` | `points` (قائمة نصوص) |
| `model` | `text` و`points` |

**التمارين (`exercises`)**: لكل تمرين `type` و`explanation`.
```json
{ "type": "mcq", "question": "...", "options": ["أ", "ب", "ج", "د"], "answer": 0, "explanation": "..." }
{ "type": "true_false", "statement": "...", "answer": true, "explanation": "..." }
{ "type": "order_words", "words": ["...", "..."], "answer": ["...", "..."],
  "alternatives": [["...", "..."]], "explanation": "..." }
```
- `answer` في الاختيار من متعدد فهرس الخيار الصحيح (يبدأ من 0)، وتُخلط الخيارات عند العرض فلا تهتم بترتيبها.
- `alternatives` (اختياري) ترتيبات أخرى صحيحة بالكلمات نفسها.
- حافظ على توازن «صح» و«خطأ» (بين 40% و60%)، فاختبار الجودة يتحقق من ذلك.

### امتحان جديد
1. أنشئ ملفاً في `app/src/main/assets/` باسم مثل `exam-s2-unit7-assessment.json`.
2. سجّله في `examAssetFiles` داخل `data/LessonRepository.kt`، وأضف معرّفه إلى `assessmentOrder` داخل `viewmodel/ArabicAppViewModel.kt`. (الامتحانات المحلية تُضاف إلى `local-exams-models.json`.)

```json
{
  "id": "exam-s2-unit7-assessment", "component": "exams", "semester": 2, "unit": 7,
  "type": "assessment", "title": "...", "subject": "...", "duration": "ساعتان", "declared_total": 20,
  "passage": { "title": "...", "text": "فقرة 1\nفقرة 2" },
  "sections": [
    { "id": "A", "title": "القراءة", "points": 8, "questions": [
      { "no": "1", "points": 1, "prompt": "...", "grading": "...",
        "answer_groups": [ { "label": "الجواب", "value": "..." } ] }
    ]},
    { "id": "C", "title": "التعبير", "points": 6, "choose_one": true,
      "topics": [ { "id": "C1", "title": "...", "prompt": "...", "model_points": ["..."] } ],
      "rubric": [ { "criterion": "...", "points": 1.5 } ] }
  ]
}
```
- **سؤال جدول**: أضف إلى السؤال `table` بالشكل `{ "headers": [...], "rows": [[...]], "answer_rows": [[...]] }`. الخانة الفارغة (`""`) في `rows` يملؤها المتعلم، و`answer_rows` فيه الجدول كاملاً. ويجب تساوي عدد الأعمدة في كل الصفوف.
- **مدة الامتحان**: «ساعتان» أو «ساعة» أو «ساعة ونصف» أو «45 دقيقة» أو «30 دقيقة» (غير ذلك يعني بلا مؤقت).

## البناء والتوقيع
- يُبنى الـ APK تلقائياً عبر GitHub Actions عند كل دفع (`.github/workflows/build-apk.yml`) وتُنشر نسخة debug في «Releases».
- **مفتاح التوقيع ثابت**: الملف `debug.keystore.base64` في جذر المستودع يمنع تغيّر المفتاح بين البناءات، فتُثبَّت كل نسخة فوق السابقة دون فقدان البيانات. وإن غاب الملف يولّد الـ workflow مفتاحاً جديداً عشوائياً ويُظهر تحذيراً. وهذا مفتاح تجريبي (debug) لا يصلح لنشر التطبيق على متجر.
- رقم النسخة (`versionCode`) يزداد تلقائياً مع رقم تشغيل الـ workflow.
- لتشغيل الاختبارات محلياً: `./gradlew testDebugUnitTest`. وهي تتحقق من سلامة بيانات الدروس والامتحانات (توازن صح/خطأ، وفهارس الإجابات، واتساق الجداول) ومن محرك التصحيح.

## هيكل الشيفرة
- `data/LessonRepository.kt`: تحميل الدروس والامتحانات من `assets` (خارج الخيط الرئيسي، والامتحانات مخزّنة مؤقتاً) وحفظ التقدم والأخطاء وجلسات الامتحانات.
- `util/ExamGrader.kt`: مطابقة الإجابات العربية وحساب النقط.
- `viewmodel/ArabicAppViewModel.kt`: حالة التطبيق، وجلسة الامتحان، والمؤقت.
- `ui/screens/`: شاشات التطبيق. `ui/theme/`: الألوان والخطوط (اتجاه RTL مفروض على كل الشاشات).
- `app/src/test/`: اختبارات الوحدة.

## حدود معروفة
- التصحيح الآلي تقديري، وقد يُظلَم جواب صحيح كُتب بكلمات مختلفة.
- لا يمكن لتطبيق عادي منع المستخدم من مغادرة التطبيق؛ يستمر المؤقت عند المغادرة.
- أسئلة الاختيار من متعدد التي جوابها الصحيح أطول من البدائل بكثير قد تدل على الجواب، وتحتاج مراجعة تربوية.
